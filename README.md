# 2-Achsen-Matrix – Kurzschulung

One-Pager-Webseite, die das methodische Arbeiten mit 2-Achsen-Methoden erklärt und kurz schult: Grundidee und die drei Aufteilungen (vier Felder, Raster mit Stufen, Zonen), Vorgehen in fünf Schritten, die Vorlagen der App – Eisenhower-Matrix, Wert/Aufwand, Macht/Interesse (Stakeholder), Risikomatrix, Stacey-Matrix, BCG-Matrix, GE-/McKinsey-Matrix, Kraljic-Matrix, Ansoff-Matrix, SWOT-Analyse, Porters Wettbewerbsstrategien, Dringlichkeit/Auswirkung, Wichtigkeit/Zufriedenheit, Situatives Führen und eigene Matrix –, Auswahlhilfe, gute Achsen und sauberes Einordnen, Anpassen und Kombinieren – mit Vorschaubildern der Food-Truck-Beispiele und Wissenscheck.

Öffnen: `index.html` direkt im Browser (keine Build-Schritte nötig).

Referenz-App: https://method-commons.github.io/two-axis-matrix-app/ ([Quellcode](https://github.com/method-commons/two-axis-matrix-app))
